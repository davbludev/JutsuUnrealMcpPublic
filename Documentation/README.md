# Jutsu Unreal MCP documentation

Jutsu Unreal MCP is an independent Unreal Engine 5.8 editor Code Plugin for Win64. It exposes a bounded MCP surface for discovering, inspecting, and authoring supported Unreal editor state. It is not an Epic Games product and does not redistribute Epic or third-party code, binaries, Python, or assets.
