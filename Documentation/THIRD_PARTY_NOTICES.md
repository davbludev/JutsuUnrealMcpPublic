The plugin interoperates with the Model Context Protocol and with MCP client software. MCP and those client applications are external software/protocols; they are not bundled, modified, or sublicensed by this plugin. Buyers must review the terms and licenses of the MCP client they choose.

If a future release adds third-party files, the release must add the dependency’s permission evidence, compatible license notices, source/binary placement under `Source/ThirdParty` where applicable, and updated Fab declarations before packaging.
